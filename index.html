Add an extension by adding one line.

  1. Upload your extension to its own GitHub repo.
  2. Add the repo to extensions.json in the store repo.
  3. Done. The store reads name, icon, version and download from GitHub.

The full setup is in README.md.

{
  "owner": "your-github-name",
  "extensions": [
    { "repo": "speed-volume-boost",
      "category": "Video & Audio" }
  ]
}
